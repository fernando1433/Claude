# Guía para quedarte con tu web (Opción A)

Tienes un archivo: `index.html`. Es tu carta completa. Media página y listo.

## 1. Cambiar la carta, precios y horario
1. Abre `index.html` con el Bloc de notas (clic derecho > Abrir con).
2. Busca el bloque que dice `CONFIGURACIÓN DEL LOCAL`. **Solo toques esa parte.**
3. Cambia textos, precios (con punto: `7.5`) y horario. Respeta las comillas y las comas.
4. Guarda. Para comprobarlo, haz doble clic en el archivo: se abre en el navegador.

Alérgenos: escribe las claves de cada plato, por ejemplo `a: ["gluten", "lacteos"]`.
Claves válidas: gluten, crustaceos, huevos, pescado, cacahuetes, soja, lacteos,
frutos_cascara, apio, mostaza, sesamo, sulfitos, altramuces, moluscos.
**Es obligatorio por ley indicarlos. Revisa cada plato nuevo.**

## 2. Publicarla (Netlify, gratis)
1. Crea cuenta en netlify.com con **tu** correo.
2. En "Sites" arrastra la carpeta que contiene `index.html`.
3. Para actualizar: Deploys > arrastra la carpeta de nuevo.

## 3. Conectar tu dominio
1. Compra el dominio **a tu nombre y con tu correo** (unos 10 €/año).
2. En Netlify: Domain management > Add a domain y sigue los pasos.
3. **El dominio se renueva cada año. Si no lo pagas, la web deja de funcionar.**

## 4. Importante
- Guarda una copia de `index.html` en tu correo o en el móvil.
- La tarjeta NFC apunta a tu dirección. Si cambias de dirección, la tarjeta ya no sirve, así que no la cambies.
